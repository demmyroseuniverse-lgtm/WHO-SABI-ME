# WHO SABI ME? Web v34

v34 adjusts the v33 economy model:

- Free platform membership.
- Buy coins with money.
- Earn coins by watching rewarded ads.
- Premium gameplay/content/features use coins.
- Creator premium packs cannot be free (minimum 1 coin).
- Rewarded ads have a daily limit and cooldown.

This release does not claim that a live ad network or payment gateway is connected. Those integrations require provider credentials, signed server callbacks/webhooks, reconciliation, refunds/chargebacks and production fraud controls.
