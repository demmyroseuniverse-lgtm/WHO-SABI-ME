# WHO SABI ME? v28 — Creator Monetization & Verification

Adds creator verification workflow, virtual-coin creator memberships, payout requests, pack view analytics, and admin review tools.

## Included
- Creator verification request/review status
- Creator pack view counter
- 30-day supporter/pro creator memberships paid with virtual coins
- 80% creator share for membership and premium-pack virtual-coin sales
- Creator payout requests with bank details masked to last 4 digits in admin UI
- Admin creator verification queue
- Admin payout review/approval/rejection

## Important production note
This release still does not move real money. Payouts are records only and must be connected to a compliant payment/payout provider, KYC/AML controls, reconciliation, fraud controls, tax reporting, withdrawal limits, audit logs, and secure webhook handling before commercial launch.
