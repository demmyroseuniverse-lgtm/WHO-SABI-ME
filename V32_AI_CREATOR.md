# WHO SABI ME? v32 — AI Creator Assistant

## Included
- Quiz idea/answer suggestions
- Caption generation
- Hashtag generation
- Difficulty estimation
- Creator content recommendations
- AI status endpoint

## Provider model
The default assistant is local and does not require an AI API key. For richer generation, a compatible server-side AI provider may be configured with `AI_API_URL` and `AI_API_KEY`. The key is kept server-side.

## Safety/content note
Generated quiz answers are suggestions, not verified facts. Creators should review generated content before publishing.
