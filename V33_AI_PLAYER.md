# WHO SABI ME? v33 — AI-Powered Player Experience

Adds a player-focused intelligence layer using server-side play history and local heuristics.

## Features
- Personalized player profile: level, daily average, multiplayer average, streak, recommended difficulty and focus area.
- Progress insights from recent daily and multiplayer results.
- AI-style game coach for stuck/win/loss situations.
- Personalized premium-pack recommendations based on marketplace activity and player level.
- Smart matchmaking queue for Easy/Normal/Hard players.
- Server-created matched games when a compatible waiting player is found.

## Notes
The v33 player assistant uses deterministic server-side heuristics by default; it does not claim to be a human coach or guarantee skill improvement. Smart matchmaking is an MVP queue and does not yet include Elo/MMR, latency matching, anti-abuse scoring, or a distributed queue service.
